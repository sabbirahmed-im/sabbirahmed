## About Sabbir Ahmed

I'm the founder of Orviton, a software company that builds simple tools to take business problems off your plate. I write about what I'm building, and I'm open to partnerships in SaaS and business.

## What I'm building

- **[ChurnPit](https://churnpit.orviton.com)**: AI churn detection that emails you a report of the customers most at risk of leaving. No dashboard needed. The waitlist is open, and early members get 50% off for as long as their subscription is active.
- **[LeadLeap](https://leadleap.app)**: discontinued.
- **[Orviton](https://www.orviton.com/)**: the company behind these products.

## About this repository

This repository contains the source code of my personal website. It is a single-page site built with HTML, CSS and vanilla JavaScript, with no build step. It includes SEO metadata, Open Graph tags, a canonical URL and schema.org `Person` markup that links my profiles together.
